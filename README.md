# Finite-Element-Analysis-with-MATLAB
I have a strong interest in computational mathematics, and Finite Element Analysis has always been one of the subjects that fascinated me. I completed coursework in Finite Element Analysis during my M.Tech at IIT Hyderabad, where I also gained practical experience implementing a thermo-structural FEM solver in MATLAB. I plan to revisit the foundational concepts, strengthen my understanding of the mathematical formulations, and practise solving engineering problems by developing and implementing numerical solutions in MATLAB.
